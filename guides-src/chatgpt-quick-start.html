Getting Started with ChatGPT

A quick-reference guide for the Blach team

ChatGPT is one of the two artificial intelligence (AI) assistants Blach provides, alongside Claude. It is one platform with a handful of tools, each suited to a different kind of work. Start a conversation in Chat, then reach for the right tool as your task grows. Here is what each one does and when to use it.

THE TOOLKIT

ChatGPT (Chat)

The everyday assistant. Ask questions, draft and edit writing, summarize documents or search the web.

USE IT WHENyou need a fast first draft, a quick summary or a clear answer

Projects

A shared folder for related chats, files and instructions, so every chat starts with the right context.

USE IT WHENyou do recurring work like proposals and want ChatGPT primed every time

Skills

Saved, reusable workflows ChatGPT applies when they fit — like our Blach branding and voice skills.

USE IT WHENyou want on-brand, consistent output without re-explaining the rules

Apps (Connectors)

Secure links to the tools we already use, such as Microsoft 365, with more Blach tools added over time.

USE IT WHENyou want ChatGPT to look things up in company files and tools

Space & Pages

Editable, shareable pages — briefs, meeting notes, team updates — organized into spaces.

USE IT WHENyou're writing a document you'll keep refining and share with the team

Sites

Turn a prompt into a web page or lightweight app, like a tracker or dashboard. Private until shared.

USE IT WHENyou want a simple interactive page without writing code

Work

Agent mode for longer jobs. It carries out multi-step research, spreadsheets, decks and reports, checking with you before key actions.

USE IT WHENa job has several steps and you want ChatGPT to run the whole sequence

New here? Start simple

Open Chat and ask ChatGPT to help with a real task you have today — a summary, an email or a first draft. Add Projects, Skills and Apps as your work grows.
